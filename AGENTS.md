# Project instructions

This Node.js and Telegraf bot controls Pi-hole remotely through Telegram on a Raspberry Pi.

Never commit `.env` or files containing secrets.

Read the guide relevant to your task:

- [Architecture and error handling](docs/agent-guides/architecture.md) for changes to bot behavior or source code.
- [Development and testing](docs/agent-guides/development.md) for local commands and tests.
- [Git workflow](docs/agent-guides/git-workflow.md) when creating a branch or commit.
